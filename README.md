# Typologist

Extract categorical schema from a corpus of documents. Built on [Toponymy](https://github.com/TutteInstitute/toponymy) and [EVoC](https://github.com/TutteInstitute/evoc).

## Status

**Pre-alpha — scaffolding only.** No working code yet. The public API is not stable and will change. Watch this space.
